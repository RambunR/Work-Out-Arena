# Work Out Arena privacy-policy website

This folder is a self-contained static website for GitHub Pages.

## Publish with GitHub Pages

1. Create a new public GitHub repository, for example `workout-arena-privacy`.
2. Upload the **contents** of this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide a public URL such as:
   `https://YOUR-GITHUB-NAME.github.io/workout-arena-privacy/`

Use the root URL for the Google Play **Privacy policy URL** and use:
`https://YOUR-GITHUB-NAME.github.io/workout-arena-privacy/delete-account.html`
for the Google Play **Account deletion URL**.

## Before publishing

- Confirm `contactus@hknovaxrproduction.com` receives privacy requests.
- Keep the Play Console Data safety answers consistent with this policy.
- Add a privacy-policy link and an account-deletion path inside the Android app.
- Update the effective date and policy whenever the app's data handling changes.
